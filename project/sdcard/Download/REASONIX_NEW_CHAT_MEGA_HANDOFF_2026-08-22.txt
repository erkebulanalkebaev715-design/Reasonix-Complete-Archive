cheap single Flash

-> conflict -> specialist
-> parallelizable -> swarm
-> Pro только если реально разрешён/нужен и budget допускает
-> early stop.

10. MOBILE RESOURCE GOVERNOR
==============================

Главная цель:
огромный проект должен оставаться usable на телефоне без сильного нагрева.

Отдельно:
remote reasoning concurrency
и

Thermal/RAM:
- NORMAL -> normal

- SEVERE -> one heavy local task
- CRITICAL -> pause builds/indexing, keep lightweight/remote work
- hysteresis/cooldown

RAM pressure:
- unload old UI/activity caches
- stop pre-index
- reduce context caches
- suspend low-priority workers
- critical -> orchestrator + active worker

Не объявлять thermal PASS без реального Android signal/device evidence.
