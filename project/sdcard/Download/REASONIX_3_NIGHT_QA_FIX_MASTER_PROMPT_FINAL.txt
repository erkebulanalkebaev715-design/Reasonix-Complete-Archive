TARGET ARCHITECTURE TO PRESERVE / BUILD FOUNDATIONS FOR

1. POWER BALANCE ENGINE
Modes: FAST | MEDIUM | HIGH; work modes also VERY_HIGH | MAXIMUM.
Speed: 1x | 2x.
Modes define limits/strategy, not fixed worker counts.
2x increases useful concurrency when safe; it never simply doubles spend.
Decision factors: expected quality gain, API cost/tokens, latency, CPU/RAM, thermal/battery/background state, conflict/verification cost, hard budget.

2. ADAPTIVE SWARM ENGINE
Goal -> estimate -> cheapest sufficient plan -> dynamic DAG -> workers -> evidence -> verification -> merge -> early stop.
Start with minimum workers; spawn only on positive marginal value; shrink as tasks finish.
Context Capsules, Shared Evidence Graph, work dedupe, write ownership/conflict control, adaptive verification, bounded hierarchy only if justified, first-class cancellation/persistence/recovery.
Worker “done” is not global PASS; evidence gates verification.
